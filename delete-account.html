طلب حذف الحساب والبيانات

يحق لأي طالب أو ولي أمر طلب حذف بيانات الطالب بالكامل من منصة SamySchool في أي وقت.

لطلب الحذف، اتبع الخطوات التالية:

  1. اضغط على زر واتساب أدناه
  2. اكتب اسم الطالب وكود الدخول الخاص به
  3. اطلب حذف البيانات نهائياً

سيتم حذف جميع البيانات المرتبطة بالكود (الاسم، سجل التقدم، النتائج) خلال 48 ساعة من الطلب.

طلب الحذف عبر واتساب
البيانات التي سيتم حذفها: اسم الطالب، كود الدخول، سجل التقدم في الوحدات، ونتائج الامتحانات.

Request Account Deletion

Any student or parent may request complete deletion of student data from the SamySchool platform at any time.

To request deletion:

  1. Tap the WhatsApp button below
  2. Provide the student's name and login code
  3. Request permanent data deletion

All data linked to the code (name, progress records, results) will be deleted within 48 hours of the request.
